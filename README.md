# Meal Auto — releases

Signed APK releases of **Meal Auto** (حجز الوجبات), an independent, unofficial student tool.
This repository holds release files only; it contains no source code.

الإصدارات الموقّعة لتطبيق «حجز الوجبات» (أداة مستقلة غير رسمية للطالب). هذا المستودع للإصدارات فقط.

The app checks `version.json` of the latest release to offer updates.
